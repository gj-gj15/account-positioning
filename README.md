# 新媒体账号定位师（account-positioning）v1.0.1

用「三环合一框架（新杠杆 / 边界变动 / 独有资源）+ 六维机会评分」帮用户确定账号方向、平台矩阵、人设定位、内容支柱与变现路径。

## 产出

- 人读定位文档
- 机读 JSON（可直接交接给双通道内容工厂 content-factory 的 `outputs/factory-config.json`）

## 使用场景

- 开新账号 / 转型现有账号前
- 需要为 content-factory 提供上游定位时

## 结构

- `SKILL.md` — 技能入口
- `references/` — 三环合一框架、交接契约

## 安装

- **通用 Agent Skill 平台（Claude / CodeBuddy / Cursor 等）**：将本目录放入平台的 skills 目录即可
- **TeleAgent / Octop**：导入本技能包后启用
